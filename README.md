## About

I build LLM systems that actually work in production.

Most of my work is in multi-agent systems, RAG pipelines, and orchestration — not just calling an API, but making these systems reliable, deterministic, and usable in real workflows. I've built a novel LLM-independent orchestration framework that pushed success rates from **43% to 81%** on a mid-tier model, proving that smart architecture beats throwing bigger models at the problem.

A lot of my focus goes toward things teams usually ignore: evaluation frameworks, tracing, prompt reliability, guardrails, and failure handling. That's where most real problems live.

I've shipped production systems across Web3, enterprise procurement, and backend automation — and I'm currently building [Tend](https://tend.so), a relationship intelligence tool for small businesses, in public.
